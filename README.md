# 핫딜 알리미

에펨코리아·뽐뿌 새 핫딜 중 **내 키워드에 맞는 글**과 **인기 딜**을 텔레그램으로 알려주는 봇입니다.

- 30분마다(새벽 3~6시 제외) 새 글 수집
  - 🛒 키워드 딜 → 모아서 3시간마다 메시지 1개로 묶어 전송 (없으면 알림 없음)
  - ⚡ 급한 키워드(예: 러닝화)나 단가 기준보다 15% 이상 싼 딜 → 바로 전송
  - 🔥 키워드와 상관없이 추천·댓글이 빠르게 붙은 인기 딜 → 인기 이유 한 줄(Gemini)과 함께 바로 전송
- 💰 단가 계산: 제목의 가격·수량으로 개당/100ml당/100g당 가격을 계산해 표시, 기준을 넘으면 제외
- 🔗 펨코·뽐뿌에 같은 상품이 올라오면 한 줄로 묶음
- 👍/👎 버튼: 👎를 누르면 Gemini가 제외어를 골라 비슷한 딜이 다시 안 오게 함
- 텔레그램에서 봇에게 말로 관리 (5분 안에 반영)
  - `단백질 알림 해줘` / `단백질 알림 꺼줘` / `키워드 목록`
  - `러닝화는 바로 알려줘` / `러닝화 묶어서 보내줘` → ⚡ 즉시 알림 켜기/끄기
  - `계란 1구 300원 이하만` / `계란 기준 없애줘` → 💰 단가 기준
  - `제로콜라 제외어 제로카페인 빼줘` → 👎로 추가된 제외어 되돌리기
- 키워드는 `keywords.json`, 인기 기준·수집 간격은 `config.yaml`

## GitHub Actions로 돌릴 때 필요한 Secret (현재는 PC 실행으로 전환, 워크플로 꺼둠)
| 이름 | 내용 |
|---|---|
| `TELEGRAM_BOT_TOKEN` | 핫딜 봇 토큰 (필수) |
| `GEMINI_API_KEY` | Gemini API 키 (연관어 확장·자연어 명령 해석용) |

## 내 PC에서 실행 (권장)
펨코(430)·뽐뿌(403) 모두 GitHub 서버(해외 IP) 접속을 막기 때문에, 딜 수집은 국내 IP인 내 PC에서 돌려야 합니다.

1. 이 저장소를 zip으로 받아 계속 둘 폴더에 풀기 (Python 3 필요)
2. 그 폴더에서 `powershell -ExecutionPolicy Bypass -File setup_pc.ps1` 실행
   → 메모장에 `.env`가 열리면 봇 토큰·Gemini 키를 붙여넣고 저장 → 한 번 더 실행
3. 작업 스케줄러에 `HotdealBot`(5분마다)이 등록됩니다. 로그는 `logs/` 폴더
4. PC로 옮긴 뒤에는 GitHub Actions의 `핫딜 알리미` 워크플로를 **Disable** 해 주세요 (텔레그램 메시지를 둘이 나눠 받는 충돌 방지)

PC가 꺼져 있는 동안의 명령은 켜진 뒤 처리됩니다(텔레그램이 24시간 보관). PC 실행 시 키워드는 로컬 `keywords.json`에만 저장됩니다.
