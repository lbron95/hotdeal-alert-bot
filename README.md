# 핫딜 알리미

에펨코리아·뽐뿌 새 핫딜 중 **내 키워드에 맞는 글만** 텔레그램으로 알려주는 봇입니다.

- 3시간마다(새벽 3~6시 제외) 새 핫딜 확인 → 맞는 딜만 메시지 1개로 묶어 전송, 없으면 알림 없음
- 텔레그램에서 봇에게 말로 키워드 관리 (15분 안에 반영)
  - `단백질 알림 해줘` → 추가 (AI가 프로틴·WPI 등 연관어 자동 포함)
  - `단백질 알림 꺼줘` → 삭제
  - `키워드 목록` → 목록 보기
- 키워드는 `keywords.json`에 저장되고 변경 시 자동 커밋

## 필요한 Secret (Settings → Secrets and variables → Actions)
| 이름 | 내용 |
|---|---|
| `TELEGRAM_BOT_TOKEN` | 핫딜 봇 토큰 (필수) |
| `GEMINI_API_KEY` | Gemini API 키 (연관어 확장·자연어 명령 해석용) |
